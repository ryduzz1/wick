Get started with Wick

  1. Let Wick see and control the game

    Wick needs Screen Recording to watch the game window and Accessibility to send input to it. It only sends input to the macro's game window while that window is focused.

  2. Try a macro on the simulator

    Choose the Simulator target and press Run. The simulator is a stand-in game, so nothing touches Roblox while you check that a macro works.

  3. Run it on Roblox

    Open a game, choose the Roblox target, and click the game window so it has focus. A small panel shows the run over the game. Press F8 from anywhere to stop.

  4. Make your own

    New macro starts a folder you can edit, or open it in Claude Code and describe the loop: Wick's agent tools let it watch the game, record you playing, and write the macro. Install macro opens ones other people share.
